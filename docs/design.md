# Portfolio design

A separate portfolio for Vishalli Maini, using facts and the avatar/resume from the supplied reference site. The existing site and unrelated local projects are untouched. The PDF supplies the exact recruiter mascot, extracted with its transparency mask. No intro video was available.

Palette: near-black #0e0a0c, maroon #301520, crimson #c33b59, rose #ef879a, pale text #f8f1f1, muted text #b5a5aa. Manrope display headings and DM Sans body copy. Hero text sits left; portrait and clickable mascot sit right. Selected work alternates explanatory diagrams and contribution descriptions. About, experience, education, recognition, and contact follow.

Chat uses a modal dialog with native focus confinement, Escape/close, suggested questions, bounded history, loading/error/retry states, and real server requests. No generated answer is faked when credentials are unavailable. Mobile stacks the hero and projects, and uses an inset chat dialog. Reduced-motion preference disables the mascot animation.
